# 🖼️ BMP to Anything — Görsel Format Dönüştürücü

BMP formatındaki görüntü dosyalarını kolay ve hızlı bir şekilde popüler formatlara (JPEG, PNG, WEBP vb.) dönüştüren, kullanıcı dostu Python Tkinter masaüstü arayüz uygulaması.

---

## ✨ Özellikler

* **Toplu Dönüştürme:** Birden fazla BMP dosyasını aynı anda seçip tek tıkla dönüştürme.
* **Geniş Format Desteği:** JPG, PNG, WEBP ve diğer popüler resim formatları.
* **Modern Masaüstü Arayüzü:** Sade, modern ve kullanımı kolay Tkinter GUI.
* **Hedef Klasör Seçimi:** Dönüştürülen dosyaların kaydedileceği konumu belirleme.

---

## 🚀 Kurulum & Çalıştırma

Gerekli Pillow kütüphanesini yükleyin:

```bash
pip install Pillow
```

Uygulamayı başlatın:

```bash
python donustur.py
```
